# UNICAR — логотип для отдела маркетинга

Оригинальный wordmark UNICAR, воссозданный в векторе (без синей точки — она была
только артефактом фавиконки сайта и к бренду не относится).

## Структура

- `svg/` — векторные мастер-файлы. Масштабируются без потери качества,
  подходят для печати и передачи дизайнерам/типографии.
- `png/` — готовые растровые экспорты в нескольких размерах.

## Файлы

| Файл | Назначение |
|---|---|
| `unicar-logo-white` | Белый логотип на прозрачном фоне — для тёмных фонов и фото |
| `unicar-logo-black` | Тёмный (#0A0A0A) на прозрачном фоне — для светлых фонов |
| `unicar-logo-white-on-blue` | Белый на фирменном синем (#49659F) — как в оригинальном баннере |
| `unicar-logo-white-on-black` | Белый на чёрной плашке |
| `unicar-mark-white` / `unicar-mark-black` | Монограмма «U» на прозрачном фоне |
| `unicar-mark-app-icon` | Монограмма «U» на тёмной квадратной плашке (иконка приложения/аватар) |

PNG-версии: wordmark — 1000 / 2000 / 4000 px по ширине; монограмма — 512 / 1024 / 2048 px.

## Правила использования

- Для любых макетов, где возможен вектор (печать, наружка, PDF), используйте SVG.
- Не растягивайте логотип непропорционально и не меняйте межбуквенные расстояния.
- Минимальный охранный отступ вокруг логотипа — высота буквы «I» (толщина штриха × 8).
- Фирменные цвета: синий `#49659F`, чёрный `#0A0A0A`, белый `#FFFFFF`.
